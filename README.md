# Applaud — CIS 300 Website Project

Course project for ASU CIS 300 (Web Development) by Tom North.

A hand-built, clean-room marketing site for **Applaud**, a service that helps
medical practices turn their existing patient list into five-star Google
reviews (pay only per posted review).

Live site: https://roosta69.github.io/cis300-applaud-site/

## Pages

- `index.html` — Home, with the HTML5 `<video>` walkthrough of the product
- `how-it-works.html` — How It Works, one example patient followed step by step
- `pricing.html` — Pricing, with the comparison table and FAQ
- `about.html` — About, the story, values and privacy promise
- `contact.html` — Contact, the demo request form (`action="#"`) and email link

## Assets

- `styles.css` — one external stylesheet shared by every page (85 selectors, 272 declarations)
- `images/` — logo, favicon, founder portrait and stills from the Applaud film
- `media/applaud-how-it-works.mp4` — 42 second film (H.264 + AAC, 720p, fast start)

Every page uses the same HTML5 header, nav, main and footer, a unique page
title, description and keywords meta tags, and the Google Analytics 4 tag.
All five pages pass the W3C Nu HTML Checker and the stylesheet passes the
W3C CSS Validator.

Built by hand in a text editor (no templates or site builders), per the course
requirements. Live site published with GitHub Pages.
